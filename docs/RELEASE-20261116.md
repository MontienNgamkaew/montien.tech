## แผนปล่อยจริง

1. ปิด auto-deploy ใน hPanel แล้ว; คงการตั้งค่านี้ไว้ก่อนเผยแพร่ commit
2. ตรวจ head/checksum ใหม่ทันที หากไม่ตรง manifest ให้หยุด ไม่ทับงานอื่น
3. ติดตั้งเฉพาะ allowlist 5 ไฟล์และจัด Git ให้สอดคล้องกับโค้ดที่ปล่อย ห้ามกด hPanel redeploy แบบ checkout ทั้ง webroot เพื่อใช้ชุดนี้
4. ตรวจ SHA256 หลังติดตั้งและ PHP syntax อีกครั้ง ตรวจหน้าเว็บเบื้องต้นโดยไม่สร้างรายการจริงหรือโหลด bootstrap ผ่าน CLI
5. หากต้องย้อน ให้ย้อนเฉพาะ 5 ไฟล์จาก rollback ชุดนี้ ไม่ restore DB หรือ `.env` ทับข้อมูลใหม่
6. คง auto-deploy ปิดไว้จนยืนยันกระบวนการ deploy ที่รักษา runtime files ได้ และบันทึก commit/ผลตรวจจริง

ตอนปิด auto-deploy ยังไม่มีการ push/ปล่อยโค้ดใหม่ ต่อมาตั้ง manual workflow และปล่อย source `9ddd74a` สำเร็จแล้ว Git checkout เดิมยัง HEAD `b56390d` ตามแผนติดตั้งเฉพาะ 5 ไฟล์ ดูเวอร์ชันที่ใช้งานจริงจาก gateway state
