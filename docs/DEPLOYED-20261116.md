## ผลตรวจ

- ก่อนเผยแพร่ ยืนยันจาก hPanel ว่า native auto-deploy ยังปิดอยู่
- ตรวจ PHP syntax ในเครื่อง 49 ไฟล์ และ gateway tests 12 กรณีผ่าน; CI ผ่าน tests และ syntax อีกครั้ง
- dedicated SSH key เชื่อมต่อ gateway ได้ และคำสั่ง shell ปกติถูกปฏิเสธ
- Environment `hostinger-production` อนุญาตเฉพาะ main มี encrypted SSH secrets แยกจากคีย์ผู้ดูแลและคืนสู่เหย้า
- Workflow deploy สำรองสามฐานข้อมูล, webroot และ persistent uploads แล้วตรวจ backup checksum ก่อนติดตั้ง
- หลัง Actions สำเร็จ ตรวจ gateway จากโฮสต์โดยตรง: ทั้ง 5 ไฟล์ SHA256 ตรงกับ source commit ที่ปล่อย
- เปรียบเทียบ `.env`, `uploads/`, รูป Man, branding Academix และ PNP Go storage กับ archive ก่อน deploy: ไม่เปลี่ยน
- เปรียบเทียบ persistent uploads กับ archive ก่อน deploy: ไม่เปลี่ยน
- HTTP static checks: Portal index, stylesheet และ Man frontend entry ตอบ 200
- ไม่สร้างบัญชี/รายการทดสอบ ไม่ล็อกอินจริง และไม่เรียก API ที่เขียนข้อมูลบน production

ผลตรวจนี้ยืนยันการติดตั้งและ static health ไม่ใช่การทดสอบ workflow ทุกบทบาทบน production ใช้ผล functional tests จาก staging ประกอบตาม `FILE-REPLACEMENT-SAFETY.md`

## Backup และ rollback

Backup ก่อนปล่อย: `/home/u651170081/backups/montien-tech/run-43807296291-1-9ddd74a1bbc6/` สำเนาในเครื่องอยู่ `backups/run-43807296291-1-9ddd74a1bbc6/` (ignored/private)

ดาวน์โหลดสำเนานอกโฮสต์เสร็จและตรวจ SHA256 ทุกไฟล์กับ gzip integrity ผ่านแล้ว ยังเป็น live backup และไม่ได้ทดสอบ import ชุดนี้ซ้ำ

โค้ดก่อนเปลี่ยนและ previous state อยู่ใต้ `/home/u651170081/releases/montien-tech/actions/run-43807296291-1-9ddd74a1bbc6/` ไม่มีการลบ backup อัตโนมัติ

หากจำเป็นต้องย้อน ให้ใช้ workflow mode `rollback` พร้อม release ID ข้างต้น จะย้อนเฉพาะโค้ด ไม่ restore DB หรือ `.env` ทับข้อมูลใหม่ Gateway จะปฏิเสธหากโค้ดจริงถูกแก้แทรก ไม่ใช่การอนุญาตให้ข้าม guard หรือใช้ hPanel redeploy

## Git บนโฮสต์

Git checkout เดิมยังมี HEAD `b56390d` และ PHP ห้าไฟล์แสดง modified ตามแผน เพราะใช้ gateway ติดตั้งเฉพาะ allowlist เวอร์ชันเว็บจริงดูจาก gateway state (`9ddd74a...`) ไม่ใช้ HEAD เดิม อย่า `reset --hard`, `clean` หรือ checkout ทั้งโฟลเดอร์เพื่อทำให้ status สะอาด เพราะอาจกระทบ runtime data
